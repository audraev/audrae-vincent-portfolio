# Audrae Vincent's website

A responsive, buildless personal portfolio. Public files live in `dist/`.

## Preview

Run `node preview.mjs` and open http://127.0.0.1:4173.

## Content

- `dist/index.html`: introduction, project cards, employer names and dates.
- `dist/app.js`: project detail notes, GitHub links, filters and navigation.
- `dist/style.css`: responsive styling and print layout.

Project descriptions were checked against the fetched GitHub `origin/main` sources on October 28, 2026. Existing project working files were not modified. The project illustrations are interface studies, not screenshots; fitness values are illustrative. Professional responsibilities beyond the supplied role descriptions have not been assumed. The experience overview can be printed or saved as PDF using the browser print dialog.

The website has no build dependencies. Google Fonts are optional; system font fallbacks are provided. Hosting identity lives in `.openai/hosting.json`.
